我的翻译

选中页面文本 → 鼠标右上角弹出浮窗 → 点击即翻译

1. 翻译接口

调用 POST /api/v1/translate，参数 q / from / to / engine / detail，读取返回里的 translation 字段。 语言代码由插件自动转换（如「日语」→ jp、「繁体中文」→ cht）。

可用变量：{{target}} 会被替换为目标语言名称。

需要在 Google Cloud 控制台启用 Cloud Translation API 并创建密钥。

可用变量：{{text}}（已转义，直接放进 JSON 字符串安全）、{{rawText}}、{{target}}、{{source}}、{{model}}。

2. 语言与行为

快捷键：Alt + T 直接翻译当前选中文本；Esc 关闭浮窗；也可右键选择「用「我的翻译」翻译选中文本」。

3. 测试连通性
